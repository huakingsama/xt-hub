XT-R1 机器人远程协作平台 · 使用说明
========================================
（把这一页发给需要用的人，照着做就能进）


一、你要先拿到两样东西
----------------------------------------
1. 地址   管理员会发你一个网址，形如  http://192.168.110.199:8000
2. 账号   管理员会发你用户名和密码

⚠️ 这份地址只在同一个 WiFi / 同一个局域网里有效。
   手机用流量、或者在家里，是打不开的（那种情况要管理员开内网穿透）。


二、打开它（电脑）
----------------------------------------
1. 连上和机器人同一个 WiFi（或者插同一台交换机）
2. 打开 Chrome / Edge
3. 地址栏原样输入管理员给你的那个地址，回车
4. 出现登录页 → 输用户名、密码 → 进入

不要加 www，不要在地址后面加空格，http:// 可以直接省略。


三、打开它（手机）
----------------------------------------
1. 手机连同一个 WiFi
2. 浏览器输入同一个地址
3. 登录后竖屏会自动变成单列，横过来看地图更舒服


四、进去以后看到什么
----------------------------------------
页面分四块：

  ┌───────────────────────────────────────┐
  │ 顶部：状态灯（雷达 Hz / 建图 / 模式）    │
  │       右侧：谁现在持有控制权            │
  ├──────────────────┬────────────────────┤
  │  实时地图（大）   │  融合视图 / 相机    │
  ├──────────────────┴────────────────────┤
  │ 底部：操作条（接管 / 启停 / 采集三维…） │
  └───────────────────────────────────────┘

· 点任意画面 → 放大，按 Esc 退出
· 右上角「3D 地图 ↗」→ 看采好的三维点云
· 顶栏「管理」只有 admin 能看到


五、两种角色，能做的事不一样
----------------------------------------
viewer（观察者）
  ✔ 看地图、看融合图、看相机、看状态
  ✘ 不能发任何指令

operator（操作者）
  ✔ viewer 的全部
  ✔ 点「接管控制权」后：键盘开车（W/S/A/D）、
    启停传感器栈、切换建图模式、采集三维
  ⚠️ 同一时刻只有 1 个人能操作。别人点了「接管」，
     你会看到提示"已被接管"，手里的方向盘就失效了。


六、操作者的标准流程
----------------------------------------
1. 点「接管控制权」（按钮变绿，顶部显示你的名字）
2. 点「传感器栈」→ 启动全部（雷达、相机、建图、画面服务）
3. 等状态灯全绿，地图开始出点
4. 键盘 W/S 前后、A/D 左右（松手自动停）
5. 要走人了 → 点「释放控制权」，让别人能接


七、连不上怎么办（按顺序排查）
----------------------------------------
1. 确认在同一个 WiFi —— 手机开热点是连不到机器人的
2. 地址有没有打错（端口号通常在最后，比如 :8000）
3. 让管理员看服务是否活着：浏览器打开  <地址>/healthz
   正常会显示  ok 19:20:31 demo=False dry=False
4. 还是不行 → 多半是防火墙，管理员在服务器那台机器上
   双击「开放防火墙-8000.bat」
5. 以上都对但页面白屏 → 按 Ctrl+F5 强制刷新（旧缓存）


八、几个别踩的坑
----------------------------------------
· 别两个人同时点「接管」再互相抢 —— 车会来回指令打架
· 采集三维时车要慢慢走，别原地转圈（点数全堆一起）
· 用完请「释放控制权」，不然别人要等 90 秒租约过期
· 密码是明文发在群里的，别拿去到处注册账号
